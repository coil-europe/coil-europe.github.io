About this COIL

Students from three universities work together in international teams to compare socio-economic challenges across European countries. Each team chooses a question about the economy, society or public policy, analyses real data with the methods of the course (correlation, regression, classification, dimensionality reduction and clustering), builds a dashboard and presents the results to everybody in a joint online session.

The COIL is part of each university's own course: students receive ECTS and are graded by their home university.

        Getting started

        Gretl

        open coil_indicators_gretl.csv
# youth unemployment vs tertiary enrolment
# and GDP per capita (all countries and years)
ols SL_UEM_1524_ZS const SE_TER_ENRR NY_GDP_PCAP_PP_KD

        Power BI / Excel

        Use coil_indicators_wide.csv: one row per country and year, one column per indicator. In Power BI: Get data → Text/CSV.

        Python (pandas)

        import pandas as pd

df = pd.read_csv("coil_indicators_long.csv")
home = df[df.iso3.isin(["ESP", "SVK", "MNE"])]
unemp = home[home.indicator == "SL.UEM.TOTL.ZS"]
unemp.pivot(index="year", columns="country", values="value")

        R (tidyverse)

        library(tidyverse)

df <- read_csv("coil_indicators_long.csv")
df |>
  filter(iso3 %in% c("ESP", "SVK", "MNE"),
         indicator == "SL.UEM.TOTL.ZS") |>
  ggplot(aes(year, value, colour = country)) + geom_line()
